### 📌 Featured Project

#### 💰 RoundVest

A full-stack **round-up investing application** inspired by Acorns.

RoundVest takes everyday purchases, calculates the spare change, and allows that amount to be invested into fractional shares.

**Built with:**

* Django + Django REST Framework
* Next.js + TypeScript
* Tailwind CSS
* Plaid transaction integration
* Alpaca fractional-share trading
* JWT authentication
* Automated backend testing

➡️ [View RoundVest](https://github.com/ahtez1/roundvest)
